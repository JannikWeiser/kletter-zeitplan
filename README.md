# Zeitplan Kletterwettkampf

Webanwendung zum Erstellen und Prüfen von Zeitplänen für Kletterwettkämpfe (Lead, Bouldern, Speed) nach dem Nationalen Regelwerk Klettern 27.1.

- Runden eingeben (Kategorie, Format, Starter, Start of Play, Wände), alles Weitere wird berechnet
- Chronologische Ablauftabelle über alle Kategorien, druck- und PDF-tauglich
- Warnungen bei Regelverstößen (z. B. Aufwärmbereich, Isolation, 1 h zwischen Lead-Runden, Wandbelegung) und gesondert bei unterschrittenen Ruhezeiten (50 min Lead-Quali, 3 Rotationen Boulder-Sets, 5 min Speed)
- Speicherung nur lokal im Browser, Export/Import als JSON

Reine statische Seite (HTML/CSS/JS), gehostet über GitHub Pages.
