# Zeitplan Kletterwettkampf

Webanwendung zum Erstellen und Prüfen von Zeitplänen für Kletterwettkämpfe (Lead, Bouldern, Speed) nach dem Nationalen Regelwerk Klettern 27.1.

1. Kategorien mit Starterzahl und Format (Vorlagen: DM, Regional-/Landesmeisterschaft, Jugendcup, Speed 2/4) eintragen
2. Zeitplan Zeile für Zeile wie in der Ausschreibung eintippen – oder mit „Zeitplan vorschlagen“ vorfüllen
3. Das Tool berechnet die Rundenenden (Rotationen, Routentausch mit 50 min Ruhezeit, Speed-Wettkampfbaum) und meldet direkt an der Zeile, wenn eine Zeit nicht zum Regelwerk passt (Aufwärmen 90/60 min, Isolation 30 min, Präsentation 2 min, Lead 1 h zwischen Runden …)

Ausgabe im Stil einer Ausschreibung, druck- und PDF-tauglich, auf Wunsch mit Startzeiten je Startplatz. Speicherung nur lokal im Browser, Export/Import als JSON. Reine statische Seite (HTML/CSS/JS), gehostet über GitHub Pages.
